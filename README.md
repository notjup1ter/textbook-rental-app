# UVA Textbook Rental App

## Overview

Welcome to the UVA Textbook Rental App – a student-friendly platform designed for UVA students to rent, buy, and sell used textbooks. This app provides a cost-effective way to access course materials while integrating features tailored to student needs.

## Features

- **User Registration and Authentication:** Users can register and log in to access the platform's features.
- **Role-Based Access Control:** Users are assigned roles of either 'librarian' or 'patron'. The role determines the level of access and functionality available to the user.
- **Librarian Dashboard:** Librarians have access to a special dashboard where they can add new books to the library's collection.
- **Book Management:** Users can explore available books, add books to their personal library, and remove them as needed.

## Roles

- **Librarian:** 
  - Can add new books to the library.
  - Access to the Librarian Dashboard.
  - Role can be assigned or changed by an admin through the Django admin interface.

- **Patron:**
  - Can explore and manage their personal library.
  - Default role for new users unless specified otherwise.

## Admin Capabilities

- **Role Management:** Admins can change user roles between 'librarian' and 'patron' using the Django admin interface. This allows for flexible management of user permissions and access levels.
